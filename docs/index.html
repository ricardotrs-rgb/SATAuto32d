Resumen

Que es esta version

SAT32D es una plataforma de automatizacion y control para consultas SAT32D, captura de clientes, gestion local de archivos y ejecuciones con Playwright.

GitHub Pages no ejecuta Python ni Flask, por eso esta exportacion solo muestra una portada estatica, la informacion principal del proyecto y los pasos para levantar la aplicacion real.

Incluye

Contenido publicado

  • Presentacion del proyecto
  • Guia corta de despliegue
  • Resumen de capacidades
  • Enlace a la ejecucion local

Limite

Lo que no hace GitHub Pages

  • No ejecuta Flask
  • No corre Playwright
  • No accede al almacenamiento local
  • No expone endpoints dinamicos

Despliegue

Como publicar esta pagina

  1. Sube el repositorio a GitHub.
  2. Activa GitHub Pages usando la rama principal y la carpeta /docs o el workflow incluido.
  3. Espera la publicacion y valida la URL que te entrega GitHub.

La app web real sigue disponible por Flask/Docker en tu VPS. Esta pagina solo sirve como exportacion estatica y portada del proyecto.
